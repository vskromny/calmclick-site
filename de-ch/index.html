Verdächtige Nachricht in der Schweiz? Erst prüfen, dann handeln

Eine SMS will eine Gebühr in Franken, eine E-Mail sieht aus wie von Ihrer Bank, ein Brief verlangt eine Zahlung? Machen Sie ein Foto oder einen Screenshot. CalmClick erklärt in einfachen Worten, worum es sich vermutlich handelt, und schlägt einen ruhigen nächsten Schritt vor. Unten finden Sie, wo Sie Betrug in der Schweiz melden können.

Laden imApp Store

Kostenlos laden. Für iPhone. 5 Prüfungen pro Monat gratis; Plus ist ein optionales kostenpflichtiges Abo.

Häufige Maschen in der Schweiz

  • Paket-SMS: Ein Paket werde zurückgehalten, bitte eine kleine Zollgebühr in Franken über einen Link bezahlen.
  • E-Banking: Eine E-Mail oder SMS verlangt, dass Sie sich über einen Link anmelden oder Ihre Karte «bestätigen».
  • Steuern: Angebliche Rückerstattung, für die Sie Ihre Kartendaten angeben sollen.
  • Online-Inserate: Ein «Käufer» schickt einen Zahlungslink, über den Sie Geld «empfangen» sollen.
  • «Hallo Mami, neue Nummer»: Ein angebliches Kind schreibt von einer unbekannten Nummer und bittet dringend um Geld.

Eine Übersicht aktueller Fälle finden Sie beim BACS.

Foto machen, einfache Antwort

Machen Sie mit CalmClick ein Foto oder einen Screenshot. Die App erklärt in einfachen Worten, worum es sich vermutlich handelt, mit einer dreistufigen Einschätzung: «Keine eindeutigen Betrugsmerkmale», «Vorsicht» oder «Warnung», jeweils mit Symbol und Wort. «Keine eindeutigen Betrugsmerkmale» heisst nicht «sicher». Ist sie unsicher, sagt sie das und versucht, eher vorsichtig zu bleiben.

Was Sie tun können

Klicken Sie nicht auf den Link, zahlen Sie nichts, bevor Sie geprüft haben, und geben Sie keine Codes oder Kartendaten weiter. Prüfen Sie direkt beim Absender, über die offizielle Website oder eine Telefonnummer, der Sie vertrauen. Verdächtige Phishing- und Betrugsnachrichten können Sie dem Bundesamt für Cybersicherheit (BACS) über dessen Meldeformular melden. CalmClick ist unabhängig vom BACS. Noch unsicher? Stellen Sie CalmClick eine Rückfrage oder zeigen Sie die Erklärung einer Vertrauensperson.

Wenn Sie schon gezahlt haben

Bleiben Sie ruhig: Das passiert vielen umsichtigen Menschen. Rufen Sie sofort Ihre Bank über die Nummer auf Ihrer Karte oder auf der offiziellen Website Ihrer Bank an; je früher, desto besser, aber eine Zahlung lässt sich nicht immer stoppen. Sie können auch Anzeige bei Ihrer Kantonspolizei erstatten. Das sind allgemeine Hinweise, keine Finanz- oder Rechtsberatung.

Ihr Foto und Ihre Prüfungen

Das Foto, das Sie auswählen, wird über unseren Server zur Analyse an OpenAI in den USA gesendet. OpenAI kann es bis zu 30 Tage aufbewahren und löscht es danach. Mehr dazu in der Datenschutzerklärung. Auch Ihre Rückfragen werden auf diesem Weg gesendet. CalmClick liest Ihre Nachrichten nicht im Hintergrund mit. Kostenlos: 5 Prüfungen pro Monat. Mit Plus, einem optionalen kostenpflichtigen Abo, sind bis zu 60 Prüfungen pro Tag möglich. Den Preis sehen Sie vor dem Kauf im App Store.

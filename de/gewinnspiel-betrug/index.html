So sieht eine gefälschte Gewinnnachricht oft aus

Eine SMS, E-Mail, ein Brief oder ein Anruf sagt, Sie hätten bei einer Lotterie oder einem Gewinnspiel gewonnen: einen Gutschein, ein Handy oder eine Reise. Um den Gewinn zu erhalten, sollen Sie eine kleine Gebühr, «Steuern» oder Versandkosten zahlen, Bank- oder Kartendaten angeben, einen Ausweis schicken, Gutscheinkarten kaufen oder eine teure Nummer anrufen. Typische Zeichen: ein Gewinn aus einer Verlosung, an die Sie sich nicht erinnern, eine Zahlung, bevor Sie etwas erhalten, eine kurze Frist, die Bitte um Verschwiegenheit und Kontaktangaben, die Sie nicht überprüfen können.

Foto machen, einfache Antwort

Machen Sie mit CalmClick ein Foto oder einen Screenshot der Nachricht oder des Briefs. Die App liest sie und erklärt in einfachen Worten, worum es sich vermutlich handelt, mit einer dreistufigen Einschätzung: «Keine eindeutigen Betrugsmerkmale», «Vorsicht» oder «Warnung», jeweils mit Symbol und Wort. «Keine eindeutigen Betrugsmerkmale» heisst nicht «sicher». Ist sie unsicher, sagt sie das und versucht, eher vorsichtig zu bleiben.

Was Sie als Nächstes tun können

Zahlen Sie nichts, geben Sie keine Bank-, Karten- oder Ausweisdaten weiter und rufen Sie keine Nummern an und klicken Sie nicht auf Links in der Nachricht. Ein echter Gewinn wird normalerweise nicht erst ausgezahlt, nachdem Sie eine Gebühr bezahlt oder Gutscheinkarten gekauft haben. Haben Sie tatsächlich an einem Gewinnspiel teilgenommen, suchen Sie den Veranstalter selbst über seine offizielle Website und fragen Sie dort direkt nach. Noch unsicher? Stellen Sie CalmClick eine Rückfrage oder zeigen Sie die Erklärung einer Vertrauensperson. Sie müssen nichts überstürzen: Eine Frist in der Nachricht ist kein Grund, vor dem Prüfen zu handeln.

Wenn Sie schon gezahlt oder Daten angegeben haben

Bleiben Sie ruhig: Das passiert vielen umsichtigen Menschen. Haben Sie gezahlt oder Karten- oder Bankdaten angegeben, rufen Sie Ihre Bank über die Nummer auf Ihrer Karte oder auf der offiziellen Website Ihrer Bank an und sagen Sie, dass es Betrug sein könnte; je früher, desto besser, aber eine Zahlung lässt sich nicht immer stoppen. Haben Sie eine Ausweiskopie geschickt, notieren Sie sich das und achten Sie auf unerwartete Briefe oder Konten. Sie können den Fall auch bei der Polizei melden. Das sind allgemeine Hinweise, keine Finanz- oder Rechtsberatung.

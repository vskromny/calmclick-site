So sieht eine gefälschte Virus-Warnung oft aus

Ein Pop-up oder eine bildschirmfüllende Seite behauptet, Ihr Telefon sei infiziert, gehackt oder gefährdet, oft mit Countdown, Warnton oder Warnzeichen. Sie sollen auf eine Schaltfläche tippen, eine App installieren, eine Nummer anrufen oder für die «Reparatur» zahlen. Seien Sie bei jeder Website vorsichtig, die Sie drängt, etwas zu installieren oder eine Nummer anzurufen, um einen Virus zu entfernen. Typische Zeichen: Alarm und Zeitdruck, ein Timer und eine Seite, die sich schwer schliessen lässt.

Foto machen, einfache Antwort

Machen Sie mit CalmClick einen Screenshot oder ein Foto der Warnung. Die App liest sie und erklärt in einfachen Worten, worum es sich vermutlich handelt, mit einer dreistufigen Einschätzung: «Keine eindeutigen Betrugsmerkmale», «Vorsicht» oder «Warnung», jeweils mit Symbol und Wort. «Keine eindeutigen Betrugsmerkmale» heisst nicht «sicher». Ist sie unsicher, sagt sie das und versucht, eher vorsichtig zu bleiben.

Was Sie als Nächstes tun können

Tippen Sie nicht auf die Schaltflächen, rufen Sie die Nummer nicht an und installieren Sie nichts aus dem Pop-up. Schliessen Sie den Browser-Tab; lässt er sich nicht schliessen, schliessen Sie die Browser-App. Optional: In den Einstellungen können Sie Verlauf und Websitedaten Ihres Browsers löschen. Dadurch werden Sie von Websites abgemeldet; tun Sie das nur, wenn Sie sich problemlos wieder anmelden können. Noch unsicher? Stellen Sie CalmClick eine Rückfrage oder senden Sie die Erklärung an eine Vertrauensperson.

Wenn Sie schon angerufen oder gezahlt haben

Bleiben Sie ruhig: Das passiert vielen umsichtigen Menschen. Haben Sie gezahlt oder Kartendaten weitergegeben, rufen Sie Ihre Bank über die Nummer auf Ihrer Karte oder auf der offiziellen Website Ihrer Bank an. Hat jemand Fernzugriff oder ein Passwort erhalten, ändern Sie dieses Passwort. Haben Sie eine App aus dem Pop-up installiert, löschen Sie sie und bitten Sie bei Unsicherheit eine Vertrauensperson um Hilfe. Das sind allgemeine Hinweise, keine Finanz- oder Rechtsberatung.

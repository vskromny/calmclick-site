So sieht eine gefälschte Rechnung oft aus

Eine E-Mail, ein Brief oder ein PDF verlangt die Zahlung einer Rechnung, die Sie nicht kennen: eine Bestellung, die Sie nie aufgegeben haben, eine unerwartete Verlängerung, eine «letzte Mahnung» oder eine Gebühr mit Frist. Manchmal sieht sie aus wie von einem bekannten Unternehmen. Typische Zeichen: eine Zahlung, die Sie keiner Bestellung zuordnen können, Zeitdruck, neue Bankverbindung, ein Link oder Anhang «zur Rechnung» und Drohungen mit Zusatzkosten.

Foto machen, einfache Antwort

Machen Sie mit CalmClick ein Foto oder einen Screenshot der Rechnung. Die App liest sie und erklärt in einfachen Worten, worum es sich vermutlich handelt, mit einer dreistufigen Einschätzung: «Keine eindeutigen Betrugsmerkmale», «Vorsicht» oder «Warnung», jeweils mit Symbol und Wort. «Keine eindeutigen Betrugsmerkmale» heisst nicht «sicher». Ist sie unsicher, sagt sie das und versucht, eher vorsichtig zu bleiben.

Was Sie als Nächstes tun können

Zahlen Sie nicht, klicken Sie keine Links und öffnen Sie keine Anhänge, bevor Sie geprüft haben. Suchen Sie die Bestellung oder den Vertrag in Ihren eigenen Unterlagen. Kontaktieren Sie das Unternehmen über die Angaben aus Ihren eigenen Unterlagen oder von seiner offiziellen Website, nicht über die Angaben auf der Rechnung. Noch unsicher? Stellen Sie CalmClick eine Rückfrage oder zeigen Sie die Erklärung einer Vertrauensperson. Prüfen Sie zügig. Ist es eine echte Rechnung, bezahlen Sie sie fristgerecht, denn eine echte Rechnung oder Mahnung, die unbezahlt bleibt, kann Mahngebühren oder Inkasso- bzw. Betreibungsschritte nach sich ziehen. Wenn Sie unsicher sind und die Frist naht, fragen Sie über Ihre eigenen Unterlagen beim Unternehmen nach und bitten Sie um mehr Zeit.

Wenn Sie schon gezahlt haben

Bleiben Sie ruhig: Das passiert vielen umsichtigen Menschen. Rufen Sie Ihre Bank über die Nummer auf Ihrer Karte oder auf der offiziellen Website Ihrer Bank an und sagen Sie, dass es eine Betrugszahlung sein könnte; je früher, desto besser, aber eine Zahlung lässt sich nicht immer stoppen. Sie können den Fall auch bei der Polizei melden. Das sind allgemeine Hinweise, keine Finanz- oder Rechtsberatung.

Auch Ihre Rückfragen werden auf diesem Weg gesendet. CalmClick liest Ihre Nachrichten nicht im Hintergrund mit. Kostenlos: 5 Prüfungen pro Monat.
